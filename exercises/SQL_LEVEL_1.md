# SQL Level 1 — Finding and Filtering Data

Use the `MockupSoftware` database. Write each query yourself; do not open `solutions/`.

1. Show every column for every employee.
2. Show employee number, first name, last name, and hire date for active employees only.
3. Find employees hired between January 1, 2024 and December 31, 2025.
4. Find employees whose last name begins with `S` or `W`.
5. Show the 10 most recently hired employees.
6. List the distinct project statuses.
7. Find clients whose status is Active or Prospect, sorted by client name.
8. Show active employees in departments 1, 3, or 5. Sort newest hire first.
9. Count all employees. Then count only active employees.
10. Count employees in each department. Use the department identifier for now.

Before Exercise 1, say aloud which table you expect to use and how you will verify its columns.
