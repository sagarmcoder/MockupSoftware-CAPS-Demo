# Database files

- `mockup-practice.db`: working SQLite database opened by DB Browser and the Node API.
- `sqlite-schema.sql`: schema used when resetting SQLite.
- `schema.sql`, `seed.sql`, `functions.sql`, `procedures.sql`, `views.sql`, and `apply-examples.sql`: inactive SQL Server/T-SQL reference files. The application does not execute them.

Reset the working database from the project root with `npm run db:reset`.
