# Database files

- `mockup-practice.db`: working SQLite database opened by DB Browser and the Node API.
- [`../../database/sqlite-schema.sql`](../../database/sqlite-schema.sql): schema used when resetting SQLite.
- [`../../database/schema.sql`](../../database/schema.sql), [`../../database/seed.sql`](../../database/seed.sql), [`../../database/functions.sql`](../../database/functions.sql), [`../../database/procedures.sql`](../../database/procedures.sql), [`../../database/views.sql`](../../database/views.sql), and [`../../database/apply-examples.sql`](../../database/apply-examples.sql): inactive SQL Server/T-SQL reference files. The application does not execute them.

Reset the working database from the project root with `npm run db:reset`.
